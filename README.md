# 🎄 圣诞贺卡工坊

一个单文件 HTML 圣诞贺卡定制网页：

- 圣诞树 8 项颜色自由调节（树身 / 装饰球 / 灯串 / 顶星 / 礼物盒 / 描边 / 夜色 / 卡底），内置 5 套预设配色
- 自定义收件人、标题、祝福文案、署名与日期
- 一键保存封面 / 内页高清 PNG
- 自动录制「封面 → 翻开 → 内页」动画视频并下载（MP4 / WebM，按浏览器支持自动选择）

## 本地使用

直接用浏览器打开 `index.html` 即可，无需构建与依赖。

## 技术说明

原生 HTML + CSS + Canvas 2D + 原生 JavaScript，无第三方运行时库；字体走自托管镜像。
